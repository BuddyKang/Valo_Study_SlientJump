# Data

`baseline_verified_trials.csv` contains the formal 10-trial baseline used in Figures 2–4.

Columns:

- `Trial`: trial order in the formal baseline.
- `T1_ms`: measured T1 in milliseconds.
- `T2_ms`: measured T2 in milliseconds.
- `Peak_Z`: maximum vertical coordinate observed for the trial.
- `Sound`: manually labeled audible (`Yes`) or silent (`No`) outcome.

The CSV is intentionally limited to the verified public summary data used by the report. Raw replay and parser outputs are not included in this repository at this stage.
